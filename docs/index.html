ホーム画面に追加する方法

一度追加すると、アプリと同じようにアイコンからSOARiAのサイトを開けます。合言葉の入力もいりません。

いまはLINEの中で開いていますLINEの中では追加できないので、画面の右上か右下にあるメニューから「Safariで開く」（Androidは「ブラウザで開く」）を選んでから、下の手順に進んでください。
  1. SafariでSOARiAのサイトを開きます。
  2. 画面の下（または上）にある 共有ボタンを押します。見当たらないときは「…」を押すと出てきます。
  3. メニューを少し下にスクロールして、「ホーム画面に追加」を押します。
  4. 名前を「SOARiA」などにして、右上の「追加」を押せば完了です。
  1. ChromeでSOARiAのサイトを開きます。
  2. 右上の メニューを押します。
  3. 「ホーム画面に追加」を押します。機種によっては「アプリをインストール」と表示されます。
  4. 名前を「SOARiA」などにして、「追加」を押せば完了です。
